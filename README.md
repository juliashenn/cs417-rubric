# CS 417 Rubric Template


## For Instructors: Creating a Rubric

1. **Open the [Rubric Template Creator](https://juliashenn.github.io/cs417-rubric/).**
2. **Create your rubric** by uploading a CSV or JSON file, or by building it directly in the browser.
3. **Download the rubric** as a JSON file when you're finished.
4. **Publish the rubric** by uploading the JSON file to the repository's `rubrics/` folder on GitHub, or by hosting it at an accessible URL.
5. **Share the rubric link** with your students.

### Viewing a Published Rubric

To view a rubric hosted in the repository's `rubrics/` folder, use the following URL format:

```text
https://juliashenn.github.io/cs417-rubric/?a=<json_file_name>
```

For example, to view `mp2a.json`:

[https://juliashenn.github.io/cs417-rubric/?a=mp2a](https://juliashenn.github.io/cs417-rubric/?a=mp2a)

Share this link with students so they can access the rubric directly.

## For Students: Completing a Rubric

1. **Open the rubric** using the link provided.
2. **Fill out the rubric** in your browser.
3. **Download your completed rubric** as a PDF.
4. **Submit the PDF** according to instructions.

### Example

[View Example Student Submission (MP2a)](https://github.com/juliashenn/cs417-rubric/blob/main/example/testing_student_MP2a.pdf)
